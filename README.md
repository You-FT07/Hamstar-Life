# 🐹 Hamster Life

ハムスターの種類や飼育方法、日常のかわいい姿を紹介するハムスター情報サイトです。

「ハムスターをもっと身近に感じてもらうこと」をコンセプトに、
やわらかく親しみやすいデザインで、ハムスターに関する情報をまとめています。

## 📖 概要

Hamster Lifeでは、ハムスターの種類ごとの特徴や飼育方法などを紹介しています。

かわいらしい写真を取り入れながら、必要な情報を分かりやすくまとめ、
初めてハムスターを飼う人でも楽しみながら見られるWebサイトを目指して制作しています。

## ✨ 主なコンテンツ

### 🐹 ハムスターの種類

以下の4種類のハムスターを紹介しています。

* ゴールデンハムスター
* ジャンガリアンハムスター
* ロボロフスキーハムスター
* キャンベルハムスター

それぞれの

* 体長
* 体重
* 寿命
* 性格

などの特徴をまとめています。

### 🏠 種類別の飼育方法

ハムスターの種類ごとに、飼育する際のポイントを紹介しています。

* ケージサイズ
* お世話のコツ
* なつかせ方

など、種類によって異なるポイントを分かりやすくまとめています。

### 📷 写真・画像

ハムスターの写真を使用し、文章だけではなく視覚的にも楽しめるデザインにしています。

画像をスライダーで表示するなど、Webサイトらしい動きも取り入れています。

## 🎨 デザイン

全体的に白と淡いグリーンを基調とし、ハムスターのかわいらしさを感じられるデザインにしています。

* 淡いグリーンをアクセントカラーに使用
* 丸みのあるカードデザイン
* やわらかい影や角丸を使用
* ハムスターの写真を大きく配置
* シンプルで見やすいレイアウト
* ホバー時のアニメーションを実装

トップページでは、ハムスターの写真にキャッチコピーを重ね、下部を波型にすることで柔らかい印象になるようにしています。
