Humstar Life（ハムスターの紹介＆飼育ガイドサイト）

ハムスターの種類ごとの特徴や、健康に長く育てるための基本的な飼育方法をまとめたWebサイトです。イベント用に制作中のプロジェクトです。

概要
「ハムスターの種類と暮らし」をテーマに、これからハムスターを飼いたい人や飼い主さんに向けて、写真や数値データ付きで分かりやすく情報を届けるWebページです。

主なコンテンツ・機能（実装予定含む）
ハムスターの種類紹介
ゴールデン、ジャンガリアン、ロボロフスキー、キャンベルなど主要な種類の体長・体重・寿命・性格を掲載
種類ごとの飼育ポイント解説へのリンク
ハムスターの基本飼育方法
飼い始めの過ごし方・環境作り
飼育に必要な基本グッズ一覧
毎日の食事や温度管理（20℃〜26℃）のポイント
種類別の詳細ケアガイド**（※順次追加予定）

使用技術
HTML5 / CSS3

今後の実装予定
各ハムスターの詳細飼育ページ（ゴールデン等のゲージサイズや詳細ケア）の作成
レスポンシブ対応（スマホ・タブレット表示の最適化）
飼育グッズチェックリスト機能
